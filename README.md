# StyleMuse

AI-powered virtual wardrobe and styling assistant with virtual try-on visualization

Built with [Builddy](https://builddy.app) — AI-powered app builder using GLM 5.1.

## Features

- User authentication with JWT tokens
- Full-body photo upload for virtual mannequin
- Batch clothing upload with AI auto-categorization
- Wardrobe browser organized by category
- AI-powered outfit suggestions
- Virtual try-on visualization on mannequin
- Occasion and weather smart filters
- Saved looks and outfit history
- Shareable outfit links
- Style analytics and insights
- Dark mode with smooth animations
- Responsive design for all devices

## Quick Start

### Local Development

```bash
npm install
npm run dev
```

Open http://localhost:3000

### Docker

```bash
docker compose up
```

### Deploy to Railway/Render

1. Push this directory to a GitHub repo
2. Connect to Railway or Render
3. It auto-detects the Dockerfile
4. Done!

## Tech Stack

- **Frontend**: HTML/CSS/JS + Tailwind CSS
- **Backend**: Express.js
- **Database**: SQLite
- **Deployment**: Docker
